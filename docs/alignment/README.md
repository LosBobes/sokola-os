# PRD ↔ App alignment reports

Generated by the `prd-align` skill. Each report checks a SOKOLA product doc
(`~/Downloads/SOKOLA/prd/*.md`) against what the app actually implements —
backend domains, OpenAPI contract, web routes, DB models and tests — and
classifies every requirement as Implemented / Partial / Missing / Conflict with
`file:line` evidence.

**Docs are authoritative for intent; the code + OpenAPI spec are authoritative
for reality. Where they disagree, that disagreement is the finding.**

Baseline commit: `3c2d074`. Re-run a report after material changes; the app
surface it was checked against is captured at the top of each file.
